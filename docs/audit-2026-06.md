## Headline

- **One true P0 survives verification:** `clearAllHeld()` never resets `spaceHeld` (js/input.js:580-588) — hold Space, alt-tab, release Space while unfocused, refocus → permanent autofire until a fresh Space press. One-line fix, conf 0.97.
- **The gz-v10 tap-to-target feature is dead across 55% of the screen on touch:** with no joystick held, any touch at x ≤ 0.55·W spawns a joystick (js/input.js:50, 308) before `resolveAimAt` can run; `RIGHT_ZONE` (js/input.js:51) is a dead variable. Research deltas independently say the zone should be ~42%.
- **Airborne targeting is broken twice:** a provably unreachable branch in `acquireTargets` (js/entities.js:1068-1069) silently drops explicit ground taps while airborne, and `footprintsNear` is called without `includeFlyers` (js/entities.js:1088) so airborne autofire can **never** auto-acquire planes — a one-token fix (`, airborne`).
- **All 6 special sprites are drawn with the wrong iso geometry:** sprites_special.js hardcodes HW=32/HH=16 (lines 41-42) vs the real 28/14; 2-tile sprites (statue, pyramid) clip 4px per side. Root cause is stale `// 32` / `// 16` comments in js/assets.js:40-41 — the codebase's "comments LIE" pattern striking again.
- **The parallax skyline renders at half resolution on the M1 iPad:** sky layers bake at 1× CSS px (js/render.js:180-183) under the dpr=2 transform (js/game.js:23); building sprites bake at dpr correctly, so only the sky is blurry.
- **PWA hygiene trio, all conf ≥0.95:** SW catch serves index.html for failed *script* fetches (sw.js:25, silent boot landmine); `Config.CACHE_VERSION` has zero programmatic link to sw.js `CACHE` (deploy footgun — bumping config does nothing); `safeSave`'s boolean is discarded everywhere (utils.js:62-64, economy.js:270) so quota/private-mode save failures lose progress silently.
- **8 of 19 tiers have only 1 building row** (prow=4 vs tierRows=3 phase mismatch, config.js:19, world.js:209/247) — an emergent, undocumented 2-2-1-1 density beat that halves income in those bands. Any fix reshapes mid-save difficulty; needs a design call.
- **9 findings refuted with proof** — including the combo-cap-unreachable claim (window is rolling per-kill, cap IS reachable) and the titan-gate income trap (built on a 1000× ROW_HP misread). Section 7 documents them so future sessions don't re-find them.

## Refuted findings (do not re-report)

- `input-joystick-consume-no-facing-update-after-releaseJoystick` — "stale Input.facing after thumb lift": taps call `faceTowardCell` and every fire runs `startAttack → facingTo(target)` (entities.js:1306-1307), so the claimed mismatch is unreachable; persistence is intentional gz-v12 design.
- `economy-combo-kill-not-hit` — "x2.0 cap unreachable": `bumpCombo` refreshes the 1.6s window on every kill (economy.js:126-130) — rolling, not fixed — so a 25-kill chain at one-shot cadence (~0.126s/kill) reaches cap in ~5-10s of dense play.
- `economy-titan-gate-income-mismatch` — entire repro built on ROW_HP[7]=12,500,000; actual value is 12,500 (config.js:23-24) — every derived number off by 1000×; no income trap exists.
- `content-mothra-mecha-missing-attack-shake` — every attack dispatcher applies an explicit non-null shake fallback (entities.js:1189/1202/1230/1253/1278); Mothra cloud shakes at 3.5, Mecha volley at 7; the proposed `shake: 0` fix would have silenced working shakes.
- `content-forms-cloud-attack-no-color` — `fireCloud` never reads `form.attack.color`; puff color is palette-driven with a hard fallback (entities.js:1221); adding the key would be a no-op.
- `audio-unlock-dom-gesture-gap` — pointerdown bubbles from HUD buttons to the window unlock listener (game.js:69); zero stopPropagation calls exist; unlock fires on every gesture anywhere in the page.
- `audio-mute-localMuted-desync` — `ui.js muted()` reads `Eco.muted` first and Economy.load() always precedes UI.init() (game.js:58/66); the cold-launch desync is unreachable; localMuted is inert while Economy exists, which is always.
- `thp-bar-stale-on-respawn` — hiding the HP bar for an undamaged target is the documented design (ui.js:180-182 comment; index.html:114-115); the gold aim ring covers which-target feedback for untouched buildings.
- `pwa-accumulator-paused-branch` is **confirmed-sound**, not refuted — listed in P2 as a no-action confirmation so it isn't re-audited.
